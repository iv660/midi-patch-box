# Updatable Project Documentation

After completing a feature, fix, or rollback, the following project documentation files should be reviewed and updated to reflect the changes made during implementation. This list serves as a checklist to ensure the project documentation stays current with the codebase.

## Documentation Files

- **[README.md](../../README.md)** - Update features, usage examples, and project overview if behavior changed or new capabilities added.
- **[ARCHITECTURE.md](../../ARCHITECTURE.md)** - Update architectural patterns, component descriptions, and design decisions if internal structure was modified.
